# Check

一个用于统计网页选中文本字符数量的 Chrome 扩展。

## 功能

选中文字后：

1. 鼠标右键
2. 点击 `check`
3. 页面右下角显示统计结果

## 统计内容

显示：

- 总计
- 中文
- 英文
- 标点
- 数字
- 排除格式符

## 统计规则

计入：

- 中文字符
- 英文字母
- 数字
- 标点符号

排除：

- 空格
- Tab
- 换行
- 其他格式字符

排除字符不会计入总数。

## 安装

1. 打开：

```
chrome://extensions/
```

2. 开启开发者模式

3. 点击「加载已解压的扩展程序」

4. 选择本目录
